⚡ Electric Vehicle (EV) Market Analysis Dashboard – Power BI
🎯 Objective

The objective of this project was to analyze the electric vehicle market to understand growth trends, popular EV types, leading manufacturers, and regional adoption patterns.

🔍 Problem Overview

With the increasing shift towards electric vehicles, it is important to understand which EV types are growing faster, which companies are leading the market, and how adoption varies across different states and years. This project focuses on visualizing these trends clearly.

🛠 Tools & Technologies Used

Power BI for dashboard development

Excel for data cleaning and preparation

Power Query for transforming raw data

DAX for key calculations and metrics

📊 Work Done in This Project

The EV dataset was cleaned and structured to remove inconsistencies and prepare it for analysis. Key factors such as vehicle type (BEV and PHEV), manufacturer, model year, state-wise distribution, and eligibility status were analyzed. An interactive dashboard was created to show total vehicles over time, top EV brands, popular models, and adoption trends. A PDF version of the dashboard was also added for quick viewing.

📈 Key Insights

Battery Electric Vehicles (BEV) dominate the market compared to Plug-in Hybrid Vehicles (PHEV)

Tesla leads the EV market with the highest number of vehicles

EV adoption has increased significantly in recent years

Some states show much higher EV adoption compared to others

Certain models like Model Y and Model 3 are the most popular

✅ Result / Outcome

The dashboard provides a clear picture of EV market growth, manufacturer performance, and adoption trends. It helps in understanding how the electric vehicle industry is evolving and where the major demand is coming from.
