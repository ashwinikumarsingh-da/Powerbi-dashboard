✈️ Airline Price Analysis Dashboard – Power BI
🎯 Objective

The main goal of this project was to analyze airline ticket prices and understand how factors like airline, number of stops, travel class, departure time, and days left before travel affect the overall price.

❓ Problem Overview

Flight ticket prices vary a lot based on different conditions, making it difficult for customers and businesses to predict pricing trends. This project focuses on identifying key price patterns to help in better planning and decision-making.

🛠 Tools & Technologies Used

Power BI for building interactive dashboards

Excel for initial data cleaning

Power Query for data transformation

DAX for price calculations and KPIs

📊 Work Performed in This Project

The raw airline dataset was cleaned and organized properly. Important columns such as airline name, ticket price, class type, stop count, departure and arrival time, and days left before travel were analyzed. An interactive Power BI dashboard was created to visualize average prices, flight distribution, and pricing trends. A PDF version of the dashboard was also included for easy viewing.

📈 Key Insights

Ticket prices vary significantly across different airlines

Flights with fewer stops generally have higher prices

Business class fares are much higher compared to economy class

Prices change based on departure time and number of days left before travel

✅ Result / Outcome

The dashboard clearly shows pricing patterns and helps compare airlines, travel classes, and flight timings. It makes it easier to understand what factors influence airline ticket prices the most.

📚 What I Learned

Through this project, I gained hands-on experience in data cleaning, building Power BI dashboards, analyzing pricing trends, and converting raw flight data into meaningful insights.
