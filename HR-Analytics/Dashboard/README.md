📊 HR Analytics Dashboard – Power BI

🎯 Objective / Problem:

This project focuses on analyzing HR employee data to understand workforce distribution, promotion trends, attrition risks, and overall employee performance. The aim was to convert raw HR data into meaningful insights for better HR planning.

🛠 Tools & Technologies Used:

Power BI was used to build the interactive dashboard. Data cleaning and preparation were done in Excel and Power Query, along with simple DAX calculations for KPIs.
📈 Work Done in This Project:

The HR dataset was cleaned and structured properly, key metrics were identified, and an interactive dashboard was created showing employee count, job levels, promotion status, salary hikes, years at company, and distance from office. A PDF version of the dashboard was also added for quick reference.
✅ Result / Outcome:

The dashboard highlighted attrition risk areas, promotion gaps, and workforce distribution across job levels, making HR trends easier to understand and analyze.
📚 Key Learnings:

This project improved my skills in data cleaning, Power BI visualization, KPI creation, and presenting business insights clearly.
